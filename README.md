# NEWSY

A full-stack Hacker News clone built with React, Ionic and Firebase, coded along the Solidsail "Learn React by Building a Hacker News Clone" course.

## About The Project

Newsy is an app that works on web, iOS, Android, Mac and Windows, shipped from one shared code base using Ionic (UI toolkit for web, mobile and desktop apps) and Firebase (serverless back-end infrastructure and deployments). It includes a main news feed, a link page for upvoting and commenting, a trending page that sorts links by upvotes, a search page, and an authentication system.

This project has been made from scratch coding along the related course.
